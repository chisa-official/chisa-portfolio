# chisa.official — Personal Portfolio

像素赛博朋克风格的个人主页网站。

Pixel cyberpunk style personal portfolio website.

## Tech Stack

- Pure HTML / CSS / JavaScript (no build tools)
- Responsive design
- Chinese / English bilingual support
- CRT scanline effects & pixel-art aesthetic

## Files

```
index.html        # Main page (inline CSS + JS)
assets/
  └── avatar.jpg  # Pixel avatar (also used as favicon)
```

## Preview

Open `index.html` in any modern browser, or serve locally:

```bash
python -m http.server 8080
```
